# My Cypress Automation

This project leverages Cypress to automate tests for login and user update features. Cypress, a JavaScript end-to-end testing framework, runs tests in a real browser for reliable results.

## Installation
```bash
npm install
```
> It is necessary to have **node** installed

## Running
```bash
npx cypress open
```
> *You open the Cypress UI*
```
npx cypress run
```
> *Run the automation by command line*
